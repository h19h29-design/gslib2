# 강서도서관 가양관 · 실제 3D 공간 탐색

## 먼저 여는 파일

**`Gayang_Library_3D.html`을 저장한 뒤 Chrome 또는 Edge로 열어주세요.**

별도의 프로그램 설치, 서버, 로그인, API 키가 필요하지 않습니다. 3D 메시, 재질 정보, 참고 도면 이미지, 실행 코드가 HTML 안에 함께 들어 있습니다. 인터넷이 차단된 상태에서도 외부 자료를 내려받지 않습니다. 채팅의 HTML 미리보기에서 실행되지 않으면 파일을 저장한 뒤 브라우저 창으로 끌어 넣어주세요. 기관에서 로컬 HTML 실행이나 그래픽 가속을 차단한 경우에는 해당 정책이 허용하는 환경이 필요합니다.

시작 화면은 **2층 내부**입니다. 정지 이미지가 아니라, 실제 모델을 마우스로 회전해서 보는 화면입니다.

## 사용법

| 하고 싶은 일 | 조작 |
|---|---|
| 회전 | 마우스 왼쪽 버튼을 누른 채 드래그 |
| 확대·축소 | 마우스 휠 또는 하단 `+ / −` |
| 화면 이동 | 오른쪽 버튼 드래그 또는 Shift + 드래그 |
| 건물 외관과 부지 보기 | 상단 `건물 전체` |
| 층 하나의 내부 보기 | `층별 내부` → 왼쪽 `B1 / 1F / 2F / 3F / 4F / RF` |
| 내부가 가려질 때 | `벽을 낮춰 내부 보기`를 켜고 절단 높이 조절. 필요하면 `외벽·창호` 끄기 |
| 여러 층의 구조 비교 | `층 분리` → 층 사이 간격 조절 |
| 건물 중간을 잘라 보기 | `단면` → 좌우·앞뒤·높이 방향과 단면 위치 조절 |
| 특정 실 찾기 | 왼쪽 공간 검색 → 실 이름 클릭. 바닥이나 이름표를 직접 클릭해도 선택 가능 |
| 사람 눈높이에서 보기 | 공간 선택 → `이 공간에서 실내 시점 보기` |
| 실내에서 이동 | W/A/S/D 또는 방향키. R/F는 높이 변경, Shift는 빠른 이동. 드래그로 시선 변경 |
| 실내 시점 나가기 | Esc 또는 `조감도로 돌아가기` |
| 원도면과 대조 | 상단 `원도면`에서 건축·토목·조경·기계설비 참고 페이지 선택 |
| 카메라를 잃어버렸을 때 | 하단 `초기화` 또는 층 다시 선택 |
| 실제 모델 저장 | 상단 `GLB 저장`. 별도로 제공된 GLB와 같은 원본 모델 |

모바일에서는 한 손가락으로 회전하고 두 손가락으로 확대·축소와 이동을 합니다. 왼쪽 위 메뉴 버튼을 누르면 층과 보기 설정이 열립니다.

## 실제로 포함한 내용

건물은 **지하 기계실, 지상 1~4층, 옥상**으로 나누었습니다. 주요 내부 구획, 계단, 승강기 코어, 책누리터의 층간 열린 공간, 테라스·데크, 외벽 프레임과 아치·창호, 일부 위생기구를 실제 3D 메시로 만들었습니다. 부지·포장·주차구획과 식재를 단순화해 함께 구성했습니다.

가구·서가·좌석은 공간 이해를 돕는 예시 모델입니다. 기계설비는 지하 저수조·펌프 및 일부 냉난방 실내외기 등을 별도 레이어로 넣었습니다. `주요 기계설비`를 켜면 표시됩니다. 옥상 태양광 패널도 형태를 단순화했습니다.

**182개 층·레이어·재질별 메시, 114,464개 삼각형, 선택 가능한 공간 구획 66개**로 구성되어 있습니다. 이 숫자는 모델 구성 수치이지 실제 건물의 객실 수·수량 산출 결과가 아닙니다.

## 도면 기준

아래 쪽수는 PDF 안의 순서입니다. 도면 자체의 도면번호와는 다릅니다.

| 도면 묶음 | 주요 기준 페이지 | 반영 범위 |
|---|---|---|
| 01 설계변경도면_건축.pdf | 37, 40, 43, 46, 49, 52쪽의 수정후 평면과 56, 59, 62, 65쪽 입면, 67, 73, 79, 82, 83쪽 단면·상세 | 층별 형태·주요 실 구획·외피·열린 공간·계단·옥상 |
| 02 설계변경도면_토목.pdf | 부지·포장·주차·배수 관련 평면, 특히 16쪽 수정후 포장계획 | 부지와 포장 구역의 상대 위치. 지형·높이와 상세는 단순화 |
| 03 설계변경도면_조경.pdf | 6, 7, 9, 10, 12, 14, 16쪽 | 식재 구역, 데크, 벤치와 층별 플랜터를 참고 |
| 04 설계변경도면_기계설비.pdf | 3~5, 9, 11~16쪽 | 주요 장비의 형태·위치와 공간 관계를 참고. 전체 설비망 아님 |

건축 수정후 도면의 주요 축 간격을 기준으로 좌표를 잡았습니다. 모델 X축은 X4에서 1번 축 쪽, Z축은 Y7에서 Y1 쪽이며, 높이 방향은 Y축입니다. 단위는 미터입니다. 주요 평면 축 범위 55 × 31m는 축 간격의 범위이며 건축면적을 뜻하지 않습니다.

## 정확도와 한계 — 중요

이 결과물은 **스캔 설계변경도면을 읽어 재구성한 공간 검토용 3D 모델**입니다. 도면 전체를 자동 변환한 CAD 파일, 모든 상세를 대조한 정밀 BIM, 현황 실측·준공 확인을 마친 모델은 아닙니다.

주요 공간 관계와 형상은 도면을 참고했지만, 벽 두께, 세부 개구부, 일부 계단·난간·마감 및 주변 부지 높이는 단순화했습니다. 도면에서 확인하지 못한 세부를 실제 시공 상태라고 단정하지 않습니다. 실 이름도 도면 표기 기준으로, 현재 운영 명칭과 다를 수 있습니다.

도면 묶음 안에는 변경전·변경후·수정후 자료가 함께 있으며, 층고와 승강기 사양, 주차 대수 등 서로 다른 표기가 있습니다. 건축 수정후 평면·입면을 우선해 모델 기준을 정했지만, 이 불일치를 준공 확인으로 해결한 것은 아닙니다. 기존 리모델링부와 신축부 지붕 높이가 다르게 표현되어 있습니다. 신축부 지붕 위 백색 외곽 프레임은 외피 스크린이지 추가 점유층이 아닙니다.

**가구 배치·서가·책·좌석·수목 수형은 예시**입니다. 기계설비는 주요 장비만 표시했고 전체 배관·덕트·소방·전기 경로, 설치 높이와 간섭은 검증하지 않았습니다. 화면 면적은 모델 구획에서 계산한 값으로, 공적 면적·견적·물량 산출·안전 판단에 사용하면 안 됩니다.

실내 자유 시점은 **벽 충돌 없는 카메라 이동**입니다. 문을 열거나 계단을 자동으로 올라가는 게임형 이동은 아닙니다. 단면은 시각적으로 잘라 보는 기능이며, 절단된 면을 채워 정확한 부재 단면을 산정하는 기능은 아닙니다.

## 파일 구성

- `Gayang_Library_3D.html` — 실행용 단일 파일. 이것만으로 이용 가능
- `Gayang_Library.glb` — 실제 3D 메시와 재질. 뷰어에서 쓰는 것과 같은 삼각형 모델
- `spaces.json` — 공간 이름·모델 좌표·구획·참고 도면 정보
- `model.json` — 웹 뷰어용 메시 버퍼, 재질, 공간 메타데이터
- `assets/drawings.json` — 원도면 비교용 이미지. 원본 PDF 전체는 포함하지 않음
- `source/` — 모델 생성 코드, 뷰어 코드, 스타일, HTML 조립 코드와 테스트
- `검증결과.md` — 실행·기능 검증 범위

GLB 메시 이름은 `층_레이어_재질` 형식입니다. 예를 들어 `01_interior_wall`은 2층 내벽입니다. `-1`=지하, `00`=1층, `01`=2층, `02`=3층, `03`=4층, `04`=옥상, `09`=부지·주변입니다. 뷰어의 층 숨기기·단면·카메라 설정은 GLB에 저장되지 않습니다. GLB에는 모든 레이어가 들어 있으므로 편집기에서 필요한 레이어를 숨겨 사용하세요.

## 소스 수정과 재생성

모델과 앱을 수정할 때만 Python이 필요합니다. 단순 열람에는 필요하지 않습니다.

```bash
python -m pip install -r source/requirements.txt
python source/build_model.py
python source/build_html.py
python source/test_model.py
```

주요 실 구획은 `source/build_model.py`의 공간·벽·바닥 정의에서 수정합니다. 실행 UI와 카메라는 `source/viewer.js`, 화면 디자인은 `source/style.css`와 `source/template.html`에서 수정합니다. `assets/drawings.json`이 있으면 HTML 조립 시 PDF를 다시 읽지 않습니다.

원본 PDF는 수정하지 않았습니다. 도면 이미지와 내부 구획 정보가 포함되어 있으므로 기관 외부에 공개할 때는 자료 공개 범위를 먼저 확인해주세요.
