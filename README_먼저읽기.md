# 가양관 3D — 현장 영상 반영 통합본

버전: 2.0-video / 작성: 2026-09-18

## 바로 실행

`index.html`을 PC의 Chrome 또는 Edge에서 여세요. 모델·도면 이미지·영상 참고 프레임·GLB 파일이 HTML 안에 포함되어 있어 별도 서버, 로그인, 인터넷 연결 없이 실행됩니다. 채팅 첨부 미리보기에서는 실행되지 않을 수 있으므로 파일을 저장한 뒤 브라우저로 여세요. WebGL2와 그래픽 가속을 사용할 수 있는 환경이 필요합니다.

처음에는 **1층 계단형 열람석의 실내 시점**이 나옵니다. 왼쪽의 여섯 시점 버튼으로 촬영 구역을 바로 이동할 수 있습니다. 작은 화면에서는 왼쪽 위 메뉴를 열면 같은 버튼이 나옵니다.

| 하고 싶은 일 | 조작 |
|---|---|
| 영상에 나온 구역으로 이동 | 계단형 열람석 / 창가 서가·책상 / 붙박이 1인 열람석 / 안내데스크 / 연녹색 계단실 / 열람공간(위치 추정) |
| 실제 장면과 비교 | 상단 **영상 대조**. 해당 프레임과 확인한 내용·추정한 내용을 따로 표시합니다. |
| 실내에서 둘러보기 | 드래그로 시선 이동, W·A·S·D로 이동, R/F 또는 상승/하강 버튼으로 높이 조절 |
| 위에서 1층 구조 보기 | 왼쪽 **1층 입체 모형** 또는 **조감도로 돌아가기** |
| 건물 전체와 다른 층 보기 | 상단 **건물 전체**, **층별 내부**, **층 분리**, **단면** 및 B1~RF 버튼 |
| 회전·확대·이동 | 조감도에서 왼쪽 드래그 / 휠 / 오른쪽 드래그 |
| 천장과 조명 숨기기 | 실내 시점에서 **실내 천장·조명** 끄기 |
| 배관·배선 표시 | **기존 설비 레이어**를 펼쳐 종류별로 켜기. 현장 검증된 선로가 아닌 개념 경로입니다. |
| 도면·프레임 크게 보기 | **참고 자료**, 또는 영상 대조 안의 **참고 프레임 크게 보기** |
| 다른 프로그램에서 모델 사용 | **GLB 저장**. 통합 형상과 재질, 층·레이어 이름을 포함합니다. |
| 현재 3D 화면 저장 | 오른쪽 위 카메라 버튼 |

**실내 이동에는 벽 충돌 판정과 자동 계단 보행을 넣지 않았습니다.** 계단을 올라갈 때는 R/F 또는 화면의 상승/하강 버튼을 같이 사용하세요. 공간 밖으로 나갔다면 왼쪽 시점 버튼이나 **처음 시점**을 누르세요. Esc는 실내 시점을 종료합니다.

## 이번에 바뀐 부분

기존 건물 전체를 지우고 새 장면만 만든 것이 아닙니다. 기존 건물 생성 소스를 기준으로 1층 촬영 구역의 예시 가구, 계단과 마감 표현을 교체했습니다.

- 넓은 목재 계단형 좌석, 밝은 연속 좌석띠, 옆의 좁은 계단과 금속 손잡이
- 반복 리브 천장, 선형 조명, 다운라이트, 프로젝터와 스피커의 단순화 형상
- 밝은 목재 붙박이 서가, 창가 1인 열람석, 긴 공용 책상과 목재 의자
- 계단 옆 통로의 긴 흰색 안내데스크, 작업대, 화면 내용을 비운 모니터와 책 수레
- 연녹색 계단실 마감과 검정 난간·목재 손잡이
- 영상 후반 열람공간의 가구 외형 — **공간 위치는 미확정**

기존의 지하층, 2~4층, 옥상과 부지 등 **1층 외 원본 메시 148개의 정점 위치가 유지됐는지 비교 검증**했습니다. 기존 66개 공간 ID와 층 기준 높이를 보존했습니다. 모델은 약 24만 개 삼각형, 249개 병합 메시로 구성됩니다.

## 영상 근거와 정확도

참고 영상: `811411999.732333_62881789719209.MP4`

이 영상은 약 150.55초, 1080×1080 해상도의 시점 편집본입니다. 카메라가 360도 촬영 장비이더라도 이 파일은 사방을 자유롭게 펼칠 수 있는 전체 구면 영상이 아닙니다. 영상의 광각 왜곡으로 곧은 천장 리브가 휘어 보이는 현상은 구조물의 실제 곡률로 모델링하지 않았습니다.

| 영상 구간 | 반영한 외형 | 아직 확인하지 못한 부분 |
|---|---|---|
| 약 00:20–00:52 | 목재 계단, 좌석띠, 옆계단, 높은 창과 난간, 천장 리브·조명 | 상세 치수, 단별 깊이, 기구 간격, 소켓 정확한 위치 |
| 약 00:52–01:23 | 창가 서가, 1인석, 공용 책상, 의자 | 모듈별 정확한 폭·높이, 책 수량과 제목 |
| 약 01:24–01:49 | 흰색 안내데스크, 책 수레, 목재 가림벽과 정보판 | 장비 모델, 회로 연결, 모든 가구 간 거리 |

건축 도면의 1층 수정후 평면(40쪽)과 책누리터 단면(79쪽)을 좌표·층간 높이 기준으로 사용했습니다. 주요 형상은 영상과 대조했지만 **사진측량·자동 3D 스캔·실측 준공 BIM은 아닙니다**. 비가시 영역, 구조 세부, 책 권수, 가구 및 기구 치수는 근사입니다. 영상에 나온 사람은 3D 모델로 만들지 않았습니다.

이 모델의 길이·면적·배관 위치를 실제 공사의 물량 산출, 시공 좌표, 안전성 판단의 기준으로 사용하지 마세요. 도면과 현장 확인이 별도로 필요합니다.

## 기존 버전과의 통합 기준

작업 기준은 앞서 제공한 `Gayang_Library_3D_Package.zip` 안의 건물 생성 소스입니다. 이번 작업 환경에서는 그다음 Systems 패키지의 원본 바이트를 다시 내려받을 수 없었습니다. 따라서 건물 원본을 재사용하고, 대화에 남아 있는 이전 설비 레이어 구성을 다시 연결했습니다. Systems 파일과 바이트 단위로 동일한 병합을 주장하지 않습니다.

기존 전력·통신·소방·급배수·냉난방 5종 레이어는 **개념 경로 표시**이며, 정확한 현장 배관·배선을 도면에서 모두 추적한 모델이 아닙니다. 이번 실내 영상으로 천장 속·벽 속 선로가 확인된 것은 아닙니다. 기본 상태에서는 숨기고, 켜면 미검증 안내가 표시됩니다. 층 분리와 개별 층 표시가 유지되도록 수직 개념 경로는 층 단위로 나눴습니다.

## 파일 구성

- `index.html`: 바로 열 수 있는 통합 뷰어. 이 파일만 있어도 실행됩니다.
- `Gayang_Library_Video.glb`: 통합 3D 메시 파일
- `model.json`: 층·공간·메시·재질·관찰 근거·추정 내용
- `observations.json`: 영상 구간별 관찰 및 추정 기록
- `assets/`: 기존 도면 참고 이미지와 선택한 영상 프레임
- `source/`: 건물 생성 및 뷰어 소스
- `검증결과.md`, `validation/`: 실제 실행 및 형상 검증 기록

원본 전체 영상과 전체 PDF는 패키지에 중복 포함하지 않았습니다. 선택한 프레임의 인물 구역은 흐림 처리했습니다. 통합 뷰어에는 도면 이미지와 실내 정보가 있으므로 공개 사이트에 올리기 전에 기관의 공개 범위를 확인하세요. 이번에는 외부 배포 없이 파일로 제공합니다.

## 소스 수정·재생성

설치 없이 보기만 할 때는 아래 과정이 필요 없습니다. 소스를 수정할 때만 Python 환경에서 실행하세요.

```sh
python -m pip install -r source/requirements.txt
python source/build_video_model.py
python source/build_html.py
```

`source/legacy_model.py`는 이전 건물 기하 생성 코드입니다. `build_video_model.py`가 이를 불러와 촬영된 1층에 변경을 적용합니다. 해당 코드의 `landmarks`에서 시점, `observations`에서 근거·추정 기록, 가구 생성 부분에서 배치를 수정할 수 있습니다.

HTML 뷰어에서 사용한 가벼운 절차적 목재·바닥 표현은 셰이더 효과입니다. GLB에는 기본 색·거칠기·금속성·투명도·발광 재질이 포함되며, 외부 3D 편집기에서 보이는 질감과 조명은 이 뷰어와 다를 수 있습니다. 화면의 절단, 현재 시점, 켜고 끈 레이어 설정은 원본 GLB에 저장되지 않습니다.

테스트용 Playwright와 Chromium은 모델을 보기 위한 필수 프로그램이 아닙니다. 제공 테스트는 별도 개발 환경에서 실행하는 용도입니다.
